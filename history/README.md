# TDG — Patrimoine historique

Ce dossier conserve les anciennes formulations TDG, les add-ons, les branches de reconstruction et les anciens ponts comme **patrimoine scientifique et documentaire**.

## Règle fondamentale

**ARCHIVÉ ≠ CANONIQUE ≠ DÉRIVÉ ≠ VALIDÉ PHYSIQUEMENT.**

Un document historique peut être :

- utile comme intuition;
- utile comme comparator ou stress test;
- pertinent comme couche IR/downstream;
- superseded par un typage plus récent;
- sandbox/exploratoire;
- fermé dans son ancien scope.

Il ne doit jamais être réinjecté dans le front courant pour contourner un no-go sans nouvelle dérivation microscopique.

## Typage historique principal

### Ancien TDG 2025 / open-system

Ancienne chaîne schématique :

`GKSL -> Gamma_mn -> lambda -> T -> Gamma_i -> deltaGamma_ij -> E_inc -> Gamma_retained -> effective gradient-flow / weak-field layer`

Aujourd'hui, cette lignée est conservée surtout comme couche **effective/downstream** possible. Elle ne doit pas être utilisée comme fondation pré-géométrique gratuite.

### Reconstruction des racines — août 2026

La branche `TDG-R — Actualization-First Root Reconstruction` était explicitement `OFF_RECORD_EXPLORATORY / SANDBOX`. Elle a servi à récupérer l'intuition conceptuelle antérieure : possibilités quantiques, factualisation/actualisation, ordre causal pré-métrique, mémoire comme trace/compression possible.

Elle ne doit pas être confondue avec un résultat final ni avec le front Root2 actuel.

### Root2 / Q-B / RC / GR

Les recoveries Root2 constituent l'historique technique principal du programme 2026. Ils contiennent les théorèmes locaux, no-go, correctifs, reproductions et firewalls nécessaires pour empêcher le retour de routes déjà fermées.
